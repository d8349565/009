## 数据流

```
用户需求
   │
   ▼
┌─────────────────────────────────────┐
│ 需求分析师 (GLM)                     │
│ • 提取关键词                         │
│ • 识别主题                           │
└────────────┬────────────────────────┘
             │ keywords, topic
             ▼
┌─────────────────────────────────────┐
│ 搜索引擎                             │
│ • SearXNG / Tavily                  │
└────────────┬────────────────────────┘
             │ search_results
             ▼
┌─────────────────────────────────────┐
│ 信息收集员 (DeepSeek)                │
│ • 批量评估数据                       │
│ • 清理和验证                         │
└────────────┬────────────────────────┘
             │ cleaned_data
             ▼
┌─────────────────────────────────────┐
│ 报告撰写员 (DeepSeek Reasoner)       │
│ • 深度推理                           │
│ • 生成报告                           │
└────────────┬────────────────────────┘
             │ draft_report
             ▼
┌─────────────────────────────────────┐
│ 质量评审员 (GLM)                     │
│ • 评估质量                           │
│ • 决定是否迭代                       │
└────────────┬────────────────────────┘
             │ final_report
             ▼
        保存到文件
```

```

    ↓

    ↓
节省 70% 成本

━━━━━━━━━━━━━━━━━━━━━

    ↓
使用 DeepSeek-Chat
    ↓
¥2.00 / 批
    ↓
高性价比

━━━━━━━━━━━━━━━━━━━━━

核心任务 (报告撰写)
    ↓
使用 DeepSeek-Reasoner
    ↓
¥4.00 / 次
    ↓
质量优先

━━━━━━━━━━━━━━━━━━━━━

总成本: ¥6-10 / 100次完整调用
对比全Reasoner: 节省 60-70%
```

```
                开始
                 │
                 ▼
        ┌────────────────┐

        └────┬───────────┘
             │

    │        │        │

┌──────┐ ┌──────┐ ┌──────────┐
│ GLM  │ │Deep- │ │DeepSeek  │
│Flash │ │Seek  │ │Reasoner  │
│      │ │Chat  │ │或        │
│快速  │ │      │ │Claude 3.5│

特殊场景:
```
