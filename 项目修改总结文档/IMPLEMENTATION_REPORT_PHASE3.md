## 📊 技术架构

### 数据流图

```
用户输入
    ↓
[需求分析] RequirementAnalyzer
    ↓ 关键词
[报告检索] ReportIndex.search()
    ↓ 相关报告列表
[内容加载] get_report_with_content()
    ↓ 报告完整数据
[综合分析] ComprehensiveReportWriter (推理模式)
    ↓ 分析结果 + 综合报告
[保存系统] save_report() + 元数据
    ↓
最终报告 (.md + .json)
```

### 核心类关系

```
ResearchAgentSystem
    ├─ RequirementAnalyzer (需求分析)
    ├─ ComprehensiveReportWriter (综合报告) ✨NEW
    ├─ ReportIndex (报告索引)
    │   ├─ search() (精确搜索)
    │   ├─ find_related_reports() (相似度匹配) ✨NEW
    │   └─ get_report_with_content() (获取完整数据) ✨NEW
    └─ DocumentParser (文档解析) ✨NEW
```

## 🎯 核心能力

### 1. 数据交叉验证

**实现层级**：
- **提示词层**: 定义验证规则和策略
- **AI推理层**: 执行实际验证和分析
- **输出层**: 结构化的验证结果

**验证维度**：
- ✅ 时间对齐检查
- ✅ 统计口径区分
- ✅ 地域范围匹配
- ✅ 来源权威性评估
- ✅ 矛盾数据识别

**输出结构**：
```json
{
  "consistent_data": [
    {
      "data_point": "数据点",
      "sources": ["来源1", "来源2"],
      "confidence": "high"
    }
  ],
  "conflicting_data": [
    {
      "data_point": "矛盾点",
      "source1": {"value": "值1", "from": "来源1"},
      "source2": {"value": "值2", "from": "来源2"},
      "analysis": "差异分析",
      "recommendation": "建议"
    }
  ]
}
```

### 2. 新洞察发现

**方法论**：
- **纵向对比**: 时间序列分析
- **横向对比**: 跨领域对比
- **因果分析**: 关联关系挖掘
- **预测推断**: 趋势外推

**示例输出**：
```json
{
  "new_insights": [
    "新能源渗透率与传统品牌市场份额呈负相关",
    "15-20万价格区间竞争最激烈",
    "智能化成为消费者决策首要因素"
  ]
}
```

### 3. 框架补充

**能力**：
- 理解用户意图
- 补充缺失章节
- 优化报告结构
- 平衡各章节权重

**输入类型**：
| 类型 | 示例 | AI处理 |
|------|------|--------|
| 纯主题 | "汽车市场分析" | 生成完整大纲 |
| 简单纲要 | "1. 概况 2. 品牌" | 补充详细子章节 |
| 详细初稿 | 完整文档 | 优化和增强 |

### 4. 内容整合

**去重策略**：
- 完全重复 → 合并来源标注
- 相似观点 → 综合提炼
- 互补信息 → 整合补充
- 矛盾信息 → 保留并说明

**整合原则**：
- 保留数据来源
- 使用脚注格式
- 标注推算数据
- 说明数据差异
