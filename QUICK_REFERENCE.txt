1. 打开 agent_config.py
2. 找到第 18 行
3. 改为你要的方案：

   AGENT_CONFIG_PRESET = "balanced"  # 混合型（推荐）⭐

   AGENT_CONFIG_PRESET = "custom"    # 自定义

4. 保存 → 重启程序 → 完成！

┌────────────────────────────────────────────────────────────┐
│ ⚙️ 配置优先级（从高到低）                                   │
└────────────────────────────────────────────────────────────┘

1️⃣ .env 中的 *_MODEL          ⭐⭐⭐⭐ 最精确（指定具体模型）
   例: REQUIREMENT_ANALYZER_MODEL=glm-4.7
       ↓
2️⃣ .env 中的 *_PROVIDER        ⭐⭐⭐ 指定供应商（自动选模型）
   例: REQUIREMENT_ANALYZER_PROVIDER=glm
       ↓
3️⃣ agent_config.py 预设方案    ⭐⭐ 推荐使用（主配置）
   例: AGENT_CONFIG_PRESET = "balanced"
       ↓
4️⃣ config.py 系统默认值        ⭐ 兜底配置
   默认: deepseek / deepseek-chat


┌────────────────────────────────────────────────────────────┐
│ 🎨 两种配置方式                                             │
└────────────────────────────────────────────────────────────┘

方式1: 只指定供应商（推荐新手） 👈 简单
────────────────────────────────
.env 文件中：
REQUIREMENT_ANALYZER_PROVIDER=glm

✅ 系统自动选择合适的模型（如 glm-4-flash）


方式2: 同时指定供应商和模型 👈 精确控制
────────────────────────────────
.env 文件中：
REQUIREMENT_ANALYZER_PROVIDER=glm
REQUIREMENT_ANALYZER_MODEL=glm-4.7  # 使用高级模型

✅ 完全控制使用哪个具体模型


┌────────────────────────────────────────────────────────────┐
│ 🆘 常见问题                                                 │
└────────────────────────────────────────────────────────────┘

Q: 修改后不生效？
A: 重启程序，Python会重新加载配置

Q: 只想改一个Agent？
A: 在 .env 中添加：
   REPORT_WRITER_PROVIDER=openrouter
   REPORT_WRITER_MODEL=xiaomi/mimo-v2-flash:free

Q: 如何选择方案？
A: 预算有限→economy，追求性价比→balanced（推荐）

Q: 配置在哪里？
A: agent_config.py（所有配置都在这个文件）

Q: 显示 "(自动选择)" 是什么意思？
A: 表示只指定了供应商，系统会自动选择该供应商的默认模型
   如需精确控制，请同时设置 *_MODEL 环境变量

Q: GLM用的是什么模型？
A: 查看 agent_config.py 中的配置，或运行 python agent_config.py
   balanced方案默认使用 glm-4-flash

Q: 如何查看正在使用的具体模型？
A: 运行 python agent_config.py，会显示所有Agent的详细配置
